# The CLI

Status: in progress
Human: marcwiest
Goal: an adopter, usually through their agent, installs, updates and removes shipyard's parts with one pinned `npx shipyard-kit@x.y.z` command instead of copying files by hand, and each release can be published to npm.
Specs touched: `docs/product/cli.md` (new), `docs/product/adoption.md`, `docs/product/agent-use.md`, `docs/product/shape.md`, `docs/product/index.md`
Out of scope: tagging and publishing `v0.1.0`, and its changelog entry; discovery stubs, which wait for skills; the plan check script; shipyard installing its own release; shipyard's `.github/` and npm's trusted publishing; AGENTS.md files below the repo root and other tools' entry files; editing a settings file that exists. The evidence tooling is throwaway repos and commands, not kept; the tests are kept.
